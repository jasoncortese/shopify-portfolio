BUILD EVIDENCE / SEPTEMBER 24, 2026

What was checked.

These are native Elementor portfolio demonstrations, with static copies of the rendered pages for easy public browsing.

Environment and scope

  • WordPress 7.1.2, Elementor Free 4.3.1, Hello Elementor 3.5.1, PHP 8.3.
  • VALE: 40 native widgets. TETHER: 38 native widgets. No HTML-widget page embeds and no Pro widgets.
  • Native containers control direction, width, gaps and responsive padding. Widgets retain editable text, imagery, button links and typography.
  • Static exports preserve the WordPress-rendered content and styles. Editor scripts and WordPress administration data are removed.

Manual visual and keyboard checks complement the layout checks. This is not a claim of complete WCAG conformance, physical-device certification or measured conversion performance.

Deliberate limitations

Products, brands and prices are fictional. No checkout, payment processing, customer accounts, email delivery or production analytics are included. Template styles can be affected by the receiving site’s theme and global settings.
